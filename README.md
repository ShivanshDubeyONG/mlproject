# Student Performance Prediction

A Flask-based Machine Learning web application that predicts a student's math score based on demographic and academic information.


## 🚀 Live Demo

👉 https://studentperformance-1voo.onrender.com


## 🚀 Tech Stack

- Python
- Flask
- Scikit-Learn
- CatBoost
- Pandas
- NumPy

## ⚙️ Features

- End-to-end ML pipeline
- Data preprocessing
- Model prediction
- Simple Flask web interface

## ▶️ Run Locally

```bash
git clone https://github.com/ShivanshDubeyONG/mlproject.git
cd mlproject
pip install -r requirements.txt
python application.py
```

Open:

```
http://127.0.0.1:5000
```
